## 1. 系统概述

智能试卷生成系统能根据您选择的**年级、学科、地域、知识点**，自动生成一份完整的试卷。系统支持：

- **9 大学科**：数学、语文、英语、物理、化学、生物、历史、地理、政治
- **K12 全学段**：小学 1 年级到高中 3 年级
- **三地域风格**：北京卷（传统文化/古诗文）、上海卷（创新思维/开放探究）、广东卷（实际应用/生活场景）
- **自动质量校验**：每题必有答案和解析，题型分布合理

## 2. 快速开始

### Web 界面

1. 打开浏览器访问 `http://localhost:8080`
2. 在左侧面板选择参数
3. 点击「生成试卷」
4. 在预览区查看、微调
5. 点击「导出 PDF」下载

### API 调用

```bash
curl -X POST http://localhost:5000/api/generate_paper \
  -H "Content-Type: application/json" \
  -d '{
    "subject": "math",
    "grade": "grade_9",
    "region": "beijing",
    "knowledge_points": ["一元二次方程", "二次函数"],
    "difficulty": 3,
    "num_questions": 10
  }'
```

## 3. 选择参数

### 3.1 年级与学科

| 学段 | 年级范围 | 可选学科 |
|------|---------|---------|
| 小学 | 1-6 年级 | 数学、语文、英语 |
| 初中 | 7-9 年级 | 数学、语文、英语、物理(8-9)、化学(9) |
| 高中 | 10-12 年级 | 数学、语文、英语、物理、化学、生物、历史、地理、政治 |

> 注意：物理从初二开始开设，化学从初三开始开设。选择不兼容的组合（如"小学二年级物理"）会被系统拒绝。

### 3.2 地域

| 地域 | 试卷风格 | 适用场景 |
|------|---------|---------|
| **北京卷** | 传统文化底蕴，古诗文默写专区，名著阅读 | 北京中考/高考备考 |
| **上海卷** | 创新思维导向，开放探究压轴，数学建模 | 上海中考/高考备考 |
| **广东卷** | 生活场景应用，商业数学，听说交际 | 广东中考/高考备考 |
| **全国卷** | 通用题型，不限定地域 | 跨地域通用练习 |

### 3.3 难度

| 等级 | 说明 | 适用场景 |
|:---:|------|---------|
| 1 | 基础巩固 | 课后练习、单元复习 |
| 2 | 较易 | 期中复习 |
| 3 | 中等 | 期末考试 |
| 4 | 较难 | 中考/高考模拟 |
| 5 | 拓展挑战 | 竞赛选拔、拔高训练 |

建议难度分布：基础 30% + 中等 50% + 困难 20%。

### 3.4 知识点

知识点分三级结构：**学科 → 一级模块 → 二级分类 → 三级知识点**。

- 输入关键词，系统会自动匹配标准知识点
- 支持多选（如同时选"一元二次方程"和"二次函数"）
- 如果不确定知识点，留空由系统自动分配

## 4. 生成试卷

### 4.1 同步生成

适合小题量（≤10 题），等待 5-15 秒直接返回：

```bash
POST /api/generate_paper
```

### 4.2 异步生成

适合大题量（>10 题），立即返回 task_id，后台生成：

```bash
# 1. 提交任务
POST /api/generate_paper_async
→ {"task_id": "abc123"}

# 2. 查询状态
GET /api/task_status/abc123
→ {"status": "running"}

# 3. 获取结果
GET /api/task_result/abc123
→ {"status": "done", "questions": [...]}
```

### 4.3 试卷结构

生成的试卷包含：

- **试卷头**：标题、副标题（地域标识）
- **密封线**：姓名、准考证号、总分、时间
- **各大题**：选择题 → 填空题 → 简答题 → 计算题 → 论述题
- **答题区**：选择题选项、填空区、解答区（自动留空）
- **页脚**：系统署名

## 5. 微调题目

### 5.1 替换单道题

对不满意的题目，可以单独替换：

```bash
POST /api/replace_question
{
  "subject": "math",
  "knowledge_points": ["一元二次方程"],
  "difficulty": 3,
  "question_index": 2,
  "current_type": "choice"
}
```

### 5.2 搜索相似题目

```bash
POST /api/search_similar
{
  "query": "勾股定理应用",
  "subject": "math",
  "top_k": 5,
  "region": "beijing"
}
```

## 6. 导出 PDF

### Web 界面

点击预览区右上角的「导出 PDF」按钮。

### 命令行

```bash
# 先生成试卷
python backend/orchestrator.py --subject math --grade 初三 --region beijing \
    --points "一元二次方程" --count 10 --output paper.html

# 然后用浏览器打开 paper.html，Ctrl+P 打印为 PDF
```

输出文件位于 `output/` 目录，包含：
- `paper_{timestamp}.html` — 试卷（可直接打印为 PDF）
- `paper_{timestamp}_answer.pdf` — 参考答案与解析（单独文件）

## 8. 质量反馈

如果您发现生成的题目有质量问题：

1. **答案错误**：记录题目 ID，通过 API 反馈
2. **题型不匹配**：检查替换题目的 `current_type` 参数
3. **地域不匹配**：确认 `region` 参数设置正确
4. **知识点偏差**：使用更精确的知识点名称

系统内置 6 道质量门禁自动检测每份试卷：
- 题量是否达标（≥ 目标的 80%）
- 每题是否都有答案（100%）
- 解析覆盖率是否 ≥ 90%
- 试卷内部是否有重复题
- 检索结果是否覆盖所需知识点
- 地域特色题是否 ≥ 1 道

## 9. 常见问题

### Q: 生成的题目太少？
A: 提高 `num_questions` 参数，或放宽 `difficulty` 范围。系统内部检索 `2x` 目标量以保证质量。

### Q: 地域特色不明显？
A: 确保 `region` 参数设置正确。系统优先使用指定地域题目，不足时自动降级到全国通用题。

### Q: 如何添加自己的题库？
A: 参考 [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md) 中的数据导入章节。

### Q: 支持哪些导出格式？
A: 当前支持 HTML（可打印为 PDF）和直接 PDF 输出。

### Q: 任务超时怎么办？
A: 异步任务超时时间为 120 秒。如果超时，尝试减少 `num_questions` 或缩小知识点范围。
