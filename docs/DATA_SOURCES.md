|------|------|

| **数据格式** | 图像 + 文本（中文简体） |
| **更新频率** | **每周**更新 |
| **覆盖学科** | 语文、数学、英语、物理、化学、生物、政治、历史、地理等 K12 全学科 |
| **覆盖年级** | K12 全学段（小学 1-6、初中 7-9、高中 10-12） |
| **标签体系** | 10+ 维度标签：学科、年级、知识点、题型、难度系数（0.1-0.9）、能力维度（布鲁姆分类）、解题步骤、答案解析含易错点 |
| **标注状态** | 完全未标注（原始数据，需自行清洗和结构化处理） |
| **地域标注** | 覆盖中国大陆，**是否包含省市标签未明确说明**（以"中国大陆"为整体定位） |
| **获取方式** | 聚合数据官网 (juhe.cn) 注册 → 实名认证 → 联系商务获取；或通过阿里云市场（market.aliyun.com）搜索「聚合数据」提交需求 |
| **费用** | **商务面议**，无公开标价；数据一经购买不支持退款 |
| **商务联系** | 客服热线 400-801-3260 / 0512-88869195 |
| **RAG 适配度** | 中等 — 数据量巨大、结构化程度高，但标注为"未标注"意味着需自行清洗和提取 QA 对；适合大规模题库构建，但前期工程投入大 |

**优点**：
- 量级大（千万级），适合作为主力题库底座
- 10+ 维度标签体系，支持精细化的知识点检索
- 每周更新，时效性好
- 专为 AI 训练和智能教育场景设计

**缺点**：
- 价格不透明，商务门槛高
- "完全未标注"意味着需要大量清洗与解析工作
- 需内部存储 3TB 级数据，硬件成本较高

## 二、免费 / 公开数据源

### 2.1 360 题库

| 属性 | 详情 |
|------|------|
| **数据规模** | 收录小升初、中考、高考历年真题及模拟试卷，具体题量未公开 |
| **数据格式** | **doc（Word 文档）**、**zip（压缩包）** |
| **覆盖学科** | 小学：语文、数学、英语、奥数；初中和高中：语文、数学、英语、政治、历史、地理、物理、化学、生物 |
| **覆盖年级** | 小学 1-6、初中 7-9、高中 10-12 |
| **标签体系** | 按学科 → 年级 → 考试类型（单元测试/期中/期末/真题/模拟）多层级分类 |
| **地域标注** | 未明确标注，部分省级真题可通过文件名或试卷标题区分 |
| **获取方式** | 直接通过网站搜索下载，无需注册、无需积分、无需付费 |
| **费用** | **完全免费** |
| **RAG 适配度** | 低 — 数据以 doc/zip 格式存在，需大量手工或脚本解析；无标准化标签，需自行提取题目、答案和知识点标注 |

**优点**：
- 完全免费，零门槛
- 覆盖升学核心场景（小升初/中考/高考）真题

**缺点**：
- 网站域名不稳定（可能已变更或停运）
- doc/zip 非结构化格式，**清洗解析工作量极大**
- 无统一标签、无标准答案格式、无知识点标注
- 数据质量参差不齐
- 时效性不确定（百科信息最后更新于 2024 年 12 月）

## 三、学术数据基准（测试与质量评估）

| 属性 | 详情 |
|------|------|
| **数据规模** | **47,734** 条 QA 对（训练 28,640 / 开发 9,547 / 测试 9,547） |

| **覆盖年级** | 1-12 年级（分 4 组：1-2 / 3-5 / 6-8 / 9-12） |
| **题型** | 开放式问答 + 多项选择题（MCQ） |
| **对齐标准** | 美国 NGSS（下一代科学教育标准） |
| **标签体系** | 年级、学科、题目类型 |
| **地域标注** | 无中国地域标签（基于 Wikipedia 英文内容生成，面向通用科学教育） |
| **获取方式** | GitHub 公开下载：https://github.com/NaumanNaeem/EduAdapt |
| **费用** | **免费**（学术用途） |
| **发布信息** | EMNLP 2025，作者来自 MBZUAI 和 UBC |
| **RAG 适配度** | 低（用于直接组卷） — 基于英文 Wikipedia 生成，非中国课程标准；适合作为**跨年级难度适配能力的评估基准**，而非直接用作中国题库 |

**优点**：
- 有明确的年级标注，适合测试模型在不同年级的题目难度适配能力
- 数据质量经五维过滤（语言适当性、年级对齐度、相关性、清晰度、学科匹配度均 ≥ 8/10）
- 开源免费，即下即用

**缺点**：
- **非中国课程标准**，不适用于国内 K12 组卷
- 基于 Wikipedia 生成（非真实考题）
- 无中国地域标签

| 属性 | 详情 |

| **数据格式** | JSON（含 LaTeX 公式、图片路径、知识点层级标注） |
| **覆盖学科** | **数学**（单一学科，K12 全学段） |
| **覆盖年级** | 小学 800 题 / 初中 5,082 题 / 高中 17,972 题 |
| **知识点体系** | **2,299 个**层级化知识点（树形括号结构，如 `圆(与圆有关的计算(弧长、扇形面积应用(...)))`） |
| **视觉元素** | 13 类（平面几何、立体几何、解析几何、流程图、条形图、折线图、饼状图等） |
| **标签体系** | 题目 ID、年级、知识点、技能维度（运算能力/推理能力等）、答案类型、多模态类别 |
| **地域标注** | 无（面向中国 K12 数学通用） |
| **获取方式** | GitHub 公开下载：https://github.com/zzli2022/CMMaTH |
| **费用** | **免费**（学术用途） |
| **发布信息** | COLING 2025，作者来自中科院自动化所、学而思 |
| **RAG 适配度** | 高 — 中国最大的中文多模态数学基准，有完整知识点标注和标准答案，可直接作为 RAG 数学题库的基础数据；同时可作数学组卷能力的评估基准 |

**优点**：
- **中国中文数学**，学科和课程标准直接匹配国内 K12
- 知识点层级标注完善（2,299 个知识点），可直接用于知识点检索
- 多模态（图文混排），适配真实数学题目形态
- 开源免费
- 是评估数学能力的事实标准

**缺点**：
- 仅覆盖数学一科
- 总量 2.3 万题，作为生产级 RAG 题库偏小
- 高中题目占比过高（75%），小学偏少（3%）

### 3.3 EduEval（层级化中文教育认知基准）

| 属性 | 详情 |
|------|------|
| **数据规模** | **超过 11,150** 道题目，覆盖 **24 种**任务类型 |
| **数据格式** | JSON（经 OCR → 标准化 → 格式化工序处理） |
| **覆盖学科** | 语文、数学、英语等 K12 核心学科（具体学科数量未详细公开） |
| **覆盖年级** | 小学、初中、高中 |
| **任务类型** | 24 种（含选择题、解答题、作文评分、课堂对话分类等） |
| **认知维度** | **6 大维度**：记忆、理解、应用、推理、创造、伦理（融合 Bloom 分类学 + Webb 知识深度模型） |
| **标签体系** | 年级、学科、任务类型、认知维度 |
| **地域标注** | 无（面向中国 K12 教育通用） |
| **获取方式** | GitHub 公开下载：https://github.com/Maerzs/E_edueval |
| **费用** | **免费**（学术用途） |
| **发布信息** | 2025 年，作者来自浙江师范大学和港科大 |
| **RAG 适配度** | 中等 — 数据来自真实中高考题目和课堂记录，题目质量高；24 种任务类型丰富，适合评估组卷系统在**不同认知层次**的出题质量 |

**优点**：
- 6 大认知维度框架，可科学评估组卷的认知层次分布
- 24 种任务类型，远超其他基准的覆盖面
- 源自真实考试和课堂数据
- 开源免费

**缺点**：
- 体积较小（1.1 万题），不足以支撑 RAG 题库
- 主要用于**评估**，非直接用作题库构建
- 标签体系偏认知维度，缺乏知识点细粒度标注

## 五、优先级推荐

### 第一阶段：快速启动（推荐立即接入）

| 优先级 | 数据源 | 理由 |
|--------|--------|------|
| **P0-1** | **CMMaTH** | 免费开源、中文学科匹配、2,299 知识点标签可直接建索引、JSON 格式即拿即用；2.3 万题可作为数学 RAG 的种子数据快速验证系统可行性 |
| **P0-2** | **NBSDC 文科简答题题库** | 免费、结构化、人工校对、聚焦文科主观题（正好是组卷难点）；配合 CMMaTH 覆盖数学后，文科方向也得到补充 |
| **P0-3** | **EduEval** | 免费、24 种任务类型 + 6 大认知维度，适合搭建**组卷质量评估框架**——每份生成的试卷可用 EduEval 的认知维度评估覆盖是否合理 |

### 第二阶段：规模化量产（验证可行后接入）

| 优先级 | 数据源 | 理由 |
|--------|--------|------|
| **P1-1** | **学科网 API** | RAG 就绪度最高（答案、解析、知识点、难度、地区 全维度标签）、2000 万+ 题量、日更新、无需本地存储；建议先用免费 4 万次额度验证 API 稳定性和数据匹配度，再与商务洽谈长期合作 |
| **P1-2** | **聚合数据 智能题库** | 数据量最大（1100 万题），适合做本地化全量题库；但需要大量清洗工作，建议在系统跑通后作为"题库底座"分批次导入 |

### 第三阶段：补充与优化（按需接入）

| 优先级 | 数据源 | 理由 |
|--------|--------|------|
| **P2-1** | **CnOpenData 教材数据** | 适合"按教材章节精准配题"场景；如果组卷系统需要严格跟随教学进度，则接入 |

### 不建议优先接入

| 数据源 | 理由 |
|--------|------|
| **360 题库** | 网站状态不稳定、doc/zip 格式清洗成本极高、无标准标签体系；仅在资源极度有限且有时间投入手工清洗时考虑 |

## 六、建议的 RAG 入库路线

```
第一周:
  ├─ 下载 CMMaTH → 解析 JSON → 按知识点建立向量索引 → 验证数学方向检索效果
  ├─ 下载 NBSDC 文科题库 → 解压 → 结构化入库 → 验证文科主观题检索效果
  └─ 下载 EduEval → 建立评估 pipeline → 定义 6 大认知维度的评估指标

第二周:
  ├─ 注册学科网开放平台 → 申请免费 4 万次额度 → 对接 API → 测试检索质量
  └─ 评估 CMMaTH + NBSDC 覆盖盲区（哪些学科/年级/题型不足）

第三周:
  └─ 根据盲区评估结果，决定是否启动聚合数据/学科网正式合作
```
